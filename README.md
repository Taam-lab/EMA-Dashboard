# 20일 신고가 눌림목 전략 — 데일리 대시보드

거래소(KRX) 데이터로 매일 자동 갱신되는 페이퍼 포트폴리오 대시보드.
전략은 백테스트 확정판(20일 신고가 눌림목 + 단계별 인버스 헷지)을 그대로 구현.

## 구성

| 파일 | 역할 |
|---|---|
| `config.py` | 전략 파라미터 (확정값) |
| `strategy.py` | 순수 전략 로직 (지표·진입·청산·헷지 판정) — 테스트 대상 |
| `data.py` | pykrx 데이터 수집 + 로컬 parquet 캐시 |
| `engine.py` | 페이퍼 포트폴리오 상태 머신 (정수 주식수 원장) |
| `run_daily.py` | 매일 배치: 데이터 갱신 → 엔진 진행 → snapshot 저장 |
| `dashboard.py` | Streamlit 2탭 대시보드 |
| `test_strategy.py` | pytest 회귀 테스트 |
| `.github/workflows/daily.yml` | 매일 07:30 KST 자동 갱신 (GitHub Actions) |

## 설치

```bash
pip install -r requirements-daily.txt
```

`requirements.txt` 는 대시보드 구동에만 필요한 것(streamlit·pandas·numpy)이고,
`requirements-daily.txt` 는 여기에 데이터 수집용 pykrx·pyarrow 를 더한 것입니다.
Streamlit Cloud 는 `requirements.txt` 만 읽으므로 배포가 가볍고 빠릅니다.

## 실행

```bash
# 1) 데이터 수집 + 포트폴리오 갱신 (첫 실행은 수백 종목이라 느립니다)
python run_daily.py

# 2) 대시보드 실행
streamlit run dashboard.py
```

`run_daily.py` 는 `portfolio_state.json`(누적 상태)과 `snapshot.json`(대시보드용 현황)을 만듭니다.
대시보드는 이 두 파일만 읽으므로 pykrx 없이도 뜹니다.

## 자동 데일리 업데이트

기본은 **GitHub Actions** 입니다 (`.github/workflows/daily.yml`, 평일 07:30 KST).

## 화면

- **메인 탭**: 포트폴리오 수익률(누적 곡선·MDD) / 현재 포지션(진입가 대비 수익률·손절선·위험표시) / 금일 진입 예정 종목 / 금일 청산 예정(위험) 종목
- **매매이력 탭**: 전체 체결 로그 + 승률·손익비·거래당 평균

## 전략 규칙 (요약)

- **유니버스**: 전일 종가 기준 시총 상위 200 → 분할·합병 아티팩트 세이프넷 제외. 보유 종목이 200위 밖으로 밀려도 청산은 규칙대로, **신규 진입만** 유니버스 제한.
- **진입**(당일 종가): 전일 20일 신고가 + 당일 −5%~0% 눌림 + 120일 모멘텀 상위 50%. 과열(코스피 이격도 EMA50 ≥120) 시 신규매수 금지.
- **청산**(셋 중 먼저): EMA 5/20 데드크로스 / 진입가 −7% / 고점 −10% 트레일. 손절·트레일은 `max(진입가×0.93, 고점×0.90)` 체결, **갭하락 시 시가 체결**.
- **사이징**: 최대 10종목 × 자본 10%, 신호 초과 시 모멘텀 우선.
- **헷지**: 코스피 이격도(EMA50) 단계별 KODEX 인버스 — 96~100→10%, 93~96→20%, <93→30% (켜짐 ≤99, 끔 ≥101). 헷지 비중만큼 롱 슬롯 축소.

## ⚠️ 반드시 알아둘 점

1. **페이퍼(모의)입니다.** 실제 주문은 하지 않습니다. 대시보드의 진입/청산 신호를 보고 증권사에서 직접 체결하세요. 자동매매로 확장하려면 Kiwoom REST 주문 API를 `engine._buy/_sell` 대신 연결해야 합니다.
2. **종가 체결 가정.** 백테스트·엔진 모두 "당일 종가 체결"을 가정합니다. 실거래는 마감 동시호가에 주문해야 하고 슬리피지가 존재합니다.
3. **라이브 유니버스는 롤링.** 백테스트는 2021 시총 고정이었지만, 여기선 매일 상위 200을 다시 뽑습니다. 따라서 라이브 성과는 백테스트와 다를 수 있습니다.
4. **수정주가 사용.** pykrx `adjusted=True` 로 분할·합병을 반영합니다. ±30.5% 필터는 데이터 오류 세이프넷용.
5. **헷지의 알려진 약점.** V자 급락-급반등(예: 2025-04 관세 쇼크)에선 바닥에서 비중을 키웠다 반등에 손실. 추세적 약세장(2022)에선 정상 작동 — 트레이드오프를 인지하고 채택한 설계.
6. **검증 상태.** walk-forward 통과(표본 외 +164~200%, 파라미터 안정). 다만 헷지 임계값은 2022년 약세장 1회 의존 — 라이브 페이퍼로 추가 검증 권장.
